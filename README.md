# 📊 Dividend Tracker · ติดตามหุ้นปันผล

เว็บแอปสำหรับติดตามพอร์ตหุ้นปันผล คำนวณรายได้ และวางแผน Passive Income
ใช้งานได้ทันทีผ่านเบราว์เซอร์ — ไม่ต้องติดตั้ง

🔗 **Live Demo:** https://kriangkraiidea.github.io/Dividend-Tracker/

---

## ✨ Features

### 📈 Portfolio Dashboard

* แสดงมูลค่าพอร์ตทั้งหมด
* คำนวณปันผลรายปี / รายเดือน (หลังภาษี)
* แสดง Yield เฉลี่ยของพอร์ต
* เปรียบเทียบกับเป้าหมายรายได้

### 📊 Stock Management

* เพิ่ม / แก้ไข / ลบ หุ้นในพอร์ต
* คำนวณ:

  * มูลค่าพอร์ต
  * ปันผลต่อปี
  * Dividend Yield
  * กำไร / ขาดทุน
* รองรับหลายหมวดอุตสาหกรรม

### 📅 Dividend Calendar

* แสดงปฏิทินรับเงินปันผล
* ดูรายรับในแต่ละเดือน
* วิเคราะห์เดือนที่รายได้สูงสุด / ไม่มีรายได้

### ⚖️ Compare หุ้น

* เปรียบเทียบหุ้นในพอร์ตแบบ side-by-side
* Highlight หุ้นที่ Yield สูงสุด

### 🧮 Dividend Calculator

* คำนวณว่า:

  * ต้องมีเงินลงทุนเท่าไหร่
  * ถึงจะได้ Passive Income ตามเป้า
* ปรับค่า:

  * Yield
  * ภาษี
  * ความถี่การจ่าย

### 📈 Investment Planner

* วางแผน DCA
* คำนวณปีที่ถึงเป้าหมาย
* รองรับ:

  * เงินต้นเริ่มต้น
  * ออมเพิ่มรายเดือน
  * Reinvest (DRIP)

### 💾 Data Management

* บันทึกข้อมูลด้วย LocalStorage
* Export / Import JSON ได้

---

## 🚀 วิธีใช้งาน

1. ไปที่หน้า **รายการหุ้น**
2. กด `+ เพิ่มหุ้นใหม่`
3. กรอกข้อมูล:

   * จำนวนหุ้น
   * ราคาต้นทุน
   * ปันผลต่อหุ้น
4. ดูภาพรวมในหน้า **Dashboard**
5. ใช้หน้า **Calculator** เพื่อวางแผนรายได้
